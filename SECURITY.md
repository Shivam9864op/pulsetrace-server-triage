# Security and data handling

PulseTrace is a local-first demo. It does not connect to or authenticate with a Minecraft server. CSV files and pasted text are processed in browser memory and are not submitted to the static-file server.

Please do not submit credentials, private player data, or logs that you do not have permission to disclose. The export redactor covers common IPv4, email, UUID, and simple token-like patterns but is not a secret scanner. Inspect exports before sharing.

To report a security concern, open a private vulnerability report through the repository's GitHub Security tab after publication. Do not post sensitive logs or credentials in a public issue.
