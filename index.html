ABOUT THIS DEMO

Evidence triage,
not a magic diagnosis.

PulseTrace compares the telemetry you provide. It does not connect to a Minecraft server, inspect packets, identify attackers or prove the root cause of an outage.

  • Missing samples count as missing in this dataset, not confirmed network packet loss.
  • TPS/MSPT trends help separate server tick pressure from network symptoms.
  • Thresholds are visible starting points; adapt them to your version, host and test setup.

All built-in scenarios are synthetic. Imported CSV and pasted logs are processed in your browser session.
